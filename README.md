# AskTrack

対面のインタビューやヒアリング中の会話をリアルタイムで文字起こしし、事前に登録した質問リストのうち「もう聞いた質問」を自動でチェックする macOS アプリです。聞き漏れを防ぎます。

> 開発中です。設計は [DESIGN.md](DESIGN.md)、タスクは [TASKS.md](TASKS.md) を参照してください。

## 動作環境

- Apple Silicon の Mac
- macOS 26 以降

## インストール

[Releases](https://github.com/h-sgy/AskTrack/releases) から最新の `AskTrack-<バージョン>.dmg` をダウンロードして開き、`AskTrack.app` を「アプリケーション」フォルダにドラッグします。以後のアップデートは、アプリ内で自動的に届きます（「アプリケーション」フォルダに移さずに起動すると、自動更新できません）。

## 使い方

1. **判定に使う LLM を設定する**: 右上の「⚙ 設定」（⌘,）で、Claude / OpenAI / Gemini から選び、ご自身の API キーを保存して「接続テスト」を押します。API キーがないと、文字起こしだけを行います。
2. **質問リストを作る**: サイドバーの ＋ でリストを作り、1 行に 1 問ずつ書きます（Return で次の行）。箇条書きのメモは「まとめて追加…」からまとめて貼り付けられます。
3. **録音する**: 「このリストで録音を始める」を押します。聞いた質問には自動でチェックが付き、根拠になった発言が表示されます。誤っていたら、質問をクリックして付け外しできます。
   - 一時停止すると、マイクを止めます。再開すると続きから録音します。
   - 停止したあとは「もう一度録音する（最初から）」で、同じ質問で新しく録音できます。
   - 「ミニウィンドウ」で、まだ聞いていない質問だけを常に前面に表示できます。
4. **書き出す**: 「Markdown で書き出す…」で、チェック結果と文字起こしを保存できます。

- マイクは、macOS の「システム設定 > サウンド > 入力」で選んでいるものを使います。対面では Mac 内蔵のマイクか有線のマイクを使い、Mac を自分と相手の間に置いてください（AirPods などは、会議アプリと同時に使うと音質が下がります）。
- 文字の大きさは、設定の「表示」で変えられます。
- 判定に「Apple オンデバイス」も選べますが、実験的な機能で精度が低く、誤ってチェックが付くことがあります。

## 送信するデータとプライバシー

- **音声はどこにも送らず、保存もしません。** 文字起こしは Mac の中（Apple の音声認識）で行います。
- 判定に外部の LLM（Claude / OpenAI / Gemini）を選んだ場合は、**書き起こしのテキストと質問リストが、そのプロバイダに送られます。** API キーはご自身のものを使い、Mac の Keychain にだけ保存します。
  - OpenAI には、応答をサーバー側に保存しない設定（`store: false`）で送ります。
  - **Gemini の無料枠のキーを使うと、送った内容が Google の製品改善に使われます。** 機密性の高いヒアリングでは、有料枠のキーを使ってください。
- Apple のオンデバイス LLM を選んだ場合は、外部に何も送りません。
- 書き起こしと判定結果は、この Mac の `~/Library/Application Support/AskTrack/` にだけ保存します。
- アップデートの確認のため、`https://h-sgy.github.io/AskTrack/appcast.xml` にアクセスします。

## 録音について

会話を録音・文字起こしするときは、事前に相手に伝えて了承を得てください。

## ビルド

```sh
brew install xcodegen   # project.yml を変更する場合のみ必要
xcodegen generate
open AskTrack.xcodeproj
```

署名は作者の証明書を前提にしています。ご自身でビルドする場合は、`project.yml` の `DEVELOPMENT_TEAM` と `CODE_SIGN_IDENTITY` を変更してください。
